# Registered Agent Skill Update Synchronization

## Criterion

기본 `proofline update`는 새 설치를 발견·등록하지 않고 중앙 매니페스트에 이미 등록된 모든 에이전트 스킬 설치를 패키지와 같은 검증된 선택 휠의 스킬 payload로 갱신해야 한다. Mutation 전에 registry와 모든 등록 target을 검사하며 `drifted`, `missing`, `conflict`, `invalid-manifest`, `unsupported`가 하나라도 있으면 기본 동기화를 전체 변경 전에 중단해야 한다. 패키지 출처·package recovery, 중단 transaction 복구와 package·target·manifest의 coherent selected-wheel identity는 `ac-0012`가 소유하는 공통 update invariant를 따라야 한다. `--no-sync-agent-skills`는 그 공통 invariant의 필수 중단 transaction 복구 뒤 package만 갱신하고 blocked registration을 `skipped-with-issues` 경고와 machine-readable result로 보고하되 agent target과 매니페스트를 변경하지 않아야 한다. `--check`는 package와 registry 전체를 변경 없이 검사하고 기본 update blocker와 package-only 선택지를 알려야 하며 별도 `--sync-agent-skills`는 제공하지 않아야 한다.

## Verification

- 성공 조건: Zero·one·multiple healthy registration fixture에서 기본 update가 등록 대상 전체를 선택하고 zero registration은 새 enrollment 없이 package-only로 성공해야 한다. `--no-sync-agent-skills`는 blocked registry에서도 agent bytes·manifest를 보존한 채 package를 갱신하고 `skipped-with-issues`를 반환해야 하며 `--check`는 zero mutation이어야 한다.
- 실패·경계 조건: Default preflight의 `drifted`, `missing`, `conflict`, `invalid-manifest`, `unsupported`에서 package와 모든 등록 target·매니페스트는 zero mutation이어야 한다. 어떤 경로도 first-time enrollment를 만들거나 `--no-sync-agent-skills`로 unresolved interrupted transaction을 건너뛰어서는 안 된다.
- 검사 방법: Source와 exact built-wheel subprocess에서 zero·one·multiple registration, blocked-state별 default/no-sync/check matrix를 실행한다. 등록 대상 선택, no-enrollment, agent target·manifest snapshot, 경고·machine-readable result와 `ac-0012` 공통 update invariant 연계를 확인한다.

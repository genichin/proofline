# 정본 산출 문서 구조 검증

## Criterion

Validator는 스키마 버전 1의 각 정본 산출 문서에 대해 필수 YAML 머리말 항목, 알 수 없는 항목 금지, 허용 상태값, 파일명과 ID 일치, 산출 문서 종류별 H1·H2 구조 및 상태별 자리표시자 규칙을 검사해야 한다. REQ `criteria`는 legacy `create/update/retire` 또는 optional `satisfy`를 포함한 네 list 형태만 허용하고, 선언된 전체 list의 합집합이 비어 있거나 같은 AC ID가 둘 이상의 list에 중복되면 해당 REQ를 오류로 판정해야 한다. 하나라도 위반하면 해당 파일을 오류로 판정하며 입력 파일을 변경하지 않아야 한다.

## Verification

- 성공 조건: 모든 산출 문서 종류와 legacy 3-field REQ 및 `satisfy`를 포함한 4-field REQ가 구조 계약을 만족하는 최소 프로젝트에서 구조 오류가 발생하지 않는다.
- 실패·경계 조건: 필수 항목 누락, 알 수 없는 항목, 잘못된 상태값, 파일명·ID 불일치, 잘못된 H1·H2, 금지된 자리표시자, 잘못된 criteria key·비-list 값·빈 합집합·list 간 중복 ID 예제마다 해당 파일이 오류로 판정되고 입력 파일은 변경되지 않는다.
- 검사 방법: 오류 유형별 fixture를 CLI로 검사하고 성공 예제는 종료 코드 0, 실패 예제는 0이 아닌 종료 코드와 파일 경로·원인 식별이 가능한 진단을 확인한다.

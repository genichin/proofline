# 결정론적 Line bootstrap 생성

## Criterion

유효한 ProofLine schema v1 Git project에서 사용자가 아직 사용되지 않은 `line-NNNN` ID와 비어 있지 않은 제목을 명시하여 Line init command를 실행하면, writer는 설치된 package에서 schema v1 canonical template을 읽어 정확한 canonical path에 `line-NNNN.md`와 `dcy-NNNN.md`를 함께 생성해야 한다. 생성된 Line은 `not_started`, Discovery는 `draft`여야 하며 ID·파일명·제목이 입력과 일치하고 일반 template variable 없이 `proofline validate`를 통과해야 한다.

## Verification

- 성공 조건: source checkout, editable install 및 wheel install 각각의 임시 Git project에서 command가 종료 코드 0을 반환하고 두 artifact가 template contract와 입력값에 맞게 생성된다.
- 실패·경계 조건: 잘못된 ID, 빈 제목 또는 사용할 수 없는 template에서는 종료 코드가 0이 아니며 생성 artifact가 남지 않는다.
- 검사 방법: 실제 CLI subprocess를 실행해 종료 코드와 생성 파일 내용을 검사하고 생성 project에서 validator를 실행한다.

# Explicit Agent Skill Repair

## Criterion

`proofline agent-skill repair`는 명시적으로 선택한 등록 설치의 유효한 매니페스트가 대상 root와 관리 경로의 ProofLine 소유권을 계속 입증하고 현재 어댑터의 대상 재확인이 일치할 때만 `drifted` 또는 `missing` 관리 파일을 현재 설치 패키지의 검증된 스킬 payload로 transaction 방식 복구해야 한다. 관리 경로 밖 파일은 변경하지 않고, 복구 후 대상과 매니페스트를 현재 package identity와 path·type·SHA-256으로 다시 기록·검증하여 `healthy`가 아니면 성공을 반환하지 않아야 한다. 소유권 핵심 필드가 invalid하거나 대상이 모호한 `invalid-manifest`에는 target repair를 수행하지 않아야 한다. 명령은 잠금과 중단 journal 복구·재확인을 새 변경 전에 수행해야 하며 status·doctor가 암묵적으로 호출해서는 안 된다.

## Verification

- 성공 조건: Valid ownership을 가진 drifted·missing fixture가 current installed package bytes로 복구되고 매니페스트와 target이 같은 identity의 `healthy`로 재검증되어야 한다.
- 실패·경계 조건: Invalid manifest, target mismatch, unmanaged conflict, outside path, unexpected file, link·reparse point, concurrent actor와 stage·replace·manifest·rollback fault에서 unowned bytes를 변경하지 않고 성공을 반환하지 않아야 한다.
- 검사 방법: Hermes·Codex fixture의 drift/missing matrix, ownership·path 공격 fixture와 transaction fault injection을 실행하고 before/after recursive snapshot, journal·backup·rollback, post-repair common health result와 invocation-owned residue 부재를 확인한다.

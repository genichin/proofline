# Official v0.2.0은 update command를 포함한 exact installable release다

## Criterion

Annotated tag `v0.2.0`과 stable GitHub Release는 exact approved candidate를 가리키며 `proofline-0.2.0-py3-none-any.whl`·`SHA256SUMS`만 upload asset으로 제공하고, public remote wheel의 installed `proofline update --check` interface와 package integrity가 검증돼야 한다.

## Verification

- Tag peeled commit, Release metadata, exact asset allowlist와 SHA-256을 local candidate에 결합한다.
- Public URL fresh download 후 strict checksum과 local wheel byte identity를 확인한다.
- Fresh non-editable environment에서 metadata version `0.2.0`, module provenance, `proofline --version`, `proofline update --help`, package resources를 검증한다.
- Representative application에서 remote wheel의 `validate`·`update --check` no-mutation을 확인한다.
- v0.1.0 one-time migration과 source `--adopt-official` 절차가 문서·skill에 존재하는지 검사한다.

# Official v0.2.1은 fixed update command를 포함한 exact corrective release다

## Criterion

이 version-specific criterion은 제품의 지속적인 acceptance condition이 아니라 corrective delivery evidence이므로 Line 0009에서 retired됐다. 아래 내용은 historical release evidence로 보존한다.

Annotated tag `v0.2.1`과 stable GitHub Release는 exact approved corrective candidate를 가리키며 `proofline-0.2.1-py3-none-any.whl`·`SHA256SUMS`만 upload asset으로 제공해야 한다. Public remote wheel에서 source installation의 `proofline update --adopt-official`과 후속 `--check`까지 실제 검증돼야 하며 initial `v0.2.0`은 overwrite·삭제하지 않는다.

## Verification

- Tag peeled commit, Release metadata, exact asset allowlist와 SHA-256을 local candidate에 결합한다.
- Public URL fresh download 후 strict checksum과 local wheel byte identity를 확인한다.
- Fresh non-editable environment에서 metadata version `0.2.1`, module provenance, `proofline --version`, `proofline update --help`, package resources를 검증한다.
- Representative application에서 remote wheel의 `validate`·`update --check` no-mutation을 확인한다.
- v0.1.0 one-time migration과 source `--adopt-official` 절차가 문서·skill에 존재하는지 검사한다.

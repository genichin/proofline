# Explicit update는 verified official wheel만 uv tool 경계에서 적용한다

## Criterion

`proofline update`는 latest 또는 explicit stable official GitHub release의 exact wheel과 checksum을 mutation 전에 검증하고, source provenance는 `--adopt-official` 없이는 보존하며, user-level `uv tool` environment만 변경한 뒤 independent post-verification을 통과해야 한다.

## Verification

- Unit·integration tests로 latest, explicit version, already-current, update-available, source adoption-required, explicit adoption, downgrade, unknown provenance, malformed release, asset mismatch, checksum mismatch, network·install·postverify failure를 실행한다.
- Checksum·release·provenance 실패에서 install subprocess가 호출되지 않았음을 확인한다.
- Isolated `UV_TOOL_DIR`·`UV_TOOL_BIN_DIR`에서 source installation과 official wheel transition을 실제 실행한다.
- Valid application fixture에서 `--check`, success, no-op와 failure 전후 recursive snapshot·Git state를 비교한다.
- 출력 status와 exit code가 계약과 일치하고 credential이 보존되지 않는지 검사한다.

# 프로젝트 설정과 canonical topology 검증

## Criterion

프로젝트 루트에서 `proofline validate`를 실행하면 validator는 `proofline.yaml`의 `schema_version: 1`과 `artifact_root: .proofline`, `.proofline`, `.proofline/lines`, `.proofline/criteria` directory 및 canonical `.proofline/identities.json` allocator가 symbolic link가 아닌 계약된 type인지 검사해야 한다. 유효한 설정과 topology에는 종료 코드 0을 반환하고, 설정 파일·필수 directory·allocator 누락, 알 수 없는 설정 항목, 잘못된 값·file type·symlink 또는 허용되지 않은 project support path에는 0이 아닌 종료 코드와 오류 경로 및 원인을 반환하며 입력을 변경하지 않아야 한다. 각 `line-NNNN` 아래의 예약 경로 `evidence/`에는 UTF-8 regular Markdown file을 둘 수 있지만, 이 문서는 canonical artifact registry, reference, allocator, status, approval, worktree readiness와 derived requirements 입력에서 제외해야 한다. `line-NNNN` root의 임의 파일·directory, `evidence/` 아래 nested directory·symlink·non-Markdown·non-regular·invalid UTF-8 path는 계속 거부해야 한다. 전환 전에 사용한 `.proofline/line-identities.json`은 opaque retained regular file로 허용하되 현재 allocator authority나 schema validation 입력으로 해석하지 않아야 한다.

## Verification

- 성공 조건: 유효한 최소 project, canonical allocator와 artifact가 있는 project 및 `line-NNNN/evidence/*.md`에 canonical ID·frontmatter·lifecycle claim 문자열을 포함하거나 포함하지 않은 UTF-8 문서가 있는 project에서 명령이 종료 코드 0을 반환한다. Evidence 문서의 존재와 내용은 canonical artifact·reference·allocator·status·approval·worktree readiness·derived requirements 의미를 바꾸지 않으며 schema-owned `.gitkeep` marker와 retained legacy ledger도 lifecycle artifact 또는 allocation authority로 해석하지 않는다.
- 실패·경계 조건: `proofline.yaml`, `.proofline`, `lines`, `criteria`, canonical allocator 누락, 알 수 없는 설정 항목, 잘못된 schema 값, directory 대신 file, symlink, Line root의 임의 support path, `evidence/`의 nested directory·symlink·non-Markdown·non-regular·invalid UTF-8 file 및 그 밖의 허용되지 않은 support path에서 0이 아닌 종료 코드와 정확한 진단을 반환하며 tree를 변경하지 않는다. Evidence 지원은 canonical Line·Discovery·REQ·AC 오류를 숨기거나 완화하지 않아야 한다.
- 검사 방법: Fresh·migrated fixture의 project root에서 source와 isolated installed-wheel CLI로 evidence positive/negative matrix를 실행하고 종료 코드, 오류 path·code·원인, canonical-like evidence의 비권위성, retained ledger 비권위성 및 실행 전후 recursive tree snapshot을 비교한다.

# 프로젝트 설정과 CLI 판정

## Criterion

프로젝트 루트에서 `proofline validate`를 실행하면 validator는 `proofline.yaml`의 `schema_version: 1`과 `artifact_root: .proofline`을 검사하고, 유효한 설정에는 종료 코드 0을, 파일 누락·알 수 없는 항목·잘못된 값에는 0이 아닌 종료 코드와 오류 파일 및 원인을 반환해야 한다.

## Verification

- 성공 조건: 유효한 최소 프로젝트 예제에서 명령이 종료 코드 0을 반환한다.
- 실패·경계 조건: 설정 파일 누락, 알 수 없는 항목, 잘못된 `schema_version` 및 잘못된 `artifact_root` 예제에서 명령이 0이 아닌 종료 코드를 반환하고 입력 파일을 변경하지 않는다.
- 검사 방법: 각 예제의 프로젝트 루트에서 CLI를 실행하고 종료 코드, 오류 파일 경로와 오류 원인을 확인한다.

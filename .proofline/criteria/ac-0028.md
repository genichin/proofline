# Agent Skill Adapter Targets and Copy Layout

## Criterion

ProofLine은 현재 실행 중인 설치 패키지에서 완전성과 경로·바이트가 검증된 `proofline-*` 스킬과 보조 파일만 지원 에이전트 대상으로 복사해야 한다. Hermes 어댑터는 실행 파일과 실제 설정을 읽기 전용으로 확인하여 선택한 프로필의 스킬 루트를 해석하고 그 아래 `proofline/` 묶음에 스킬 디렉터리를 배치해야 한다. Codex 어댑터는 실행 파일과 공식 사용자 범위를 확인하여 `$HOME/.agents/skills/proofline-*/` 평면 구조에 배치해야 한다. 대상 경로는 운영체제 사용자 환경과 에이전트 설정으로 계산하며 특정 사용자의 절대 경로를 기본값으로 고정하지 않아야 한다. 설치는 복사 전용이어야 하며 링크·재분석 지점, 에이전트 설정 수정, 인접 source checkout과 영속 중간 원본을 사용하지 않아야 한다. 알 수 없는 에이전트·프로필, 모호하거나 지원되지 않는 배치와 불완전·안전하지 않은 패키지 자원은 대상 변경 전에 거부해야 한다. 저장소 source와 exact wheel은 같은 managed relative skill inventory와 bytes를 제공해야 한다.

## Verification

- 성공 조건: 격리된 Hermes default·named profile과 Codex user fixture에서 어댑터가 실제 설정·환경으로 target root를 결정하고 각각 grouped·flat topology에 source 또는 installed-wheel의 exact skill inventory와 bytes를 준비해야 한다.
- 실패·경계 조건: Missing executable·config·profile, ambiguous target, unsupported scope, package identity·inventory·path·hash 오류, symlink·hard link·junction·reparse point와 대상 이탈에서 target·agent config·project에 zero mutation이어야 한다.
- 검사 방법: Source↔wheel archive inventory·byte parity, Unix·Windows path fixture, Hermes profile/Codex user adapter matrix와 package-resource fault injection을 실행하고 실제 사용자 HOME·설정·스킬 경로가 불변임을 snapshot으로 확인한다.

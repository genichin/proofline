# Fail-closed and idempotent user harness initialization

## Criterion

`proofline init`은 absent `~/.proofline/`을 단일 managed tree로 생성하고 exact managed bytes 재실행은 no-op이어야 하며, existing mismatch·unexpected entry·symlink·concurrent target appearance 또는 staging/commit failure가 있으면 기존 user files를 overwrite·delete하거나 partial initialization을 남기지 않아야 한다.

## Verification

- 성공 조건: Fresh isolated HOME init과 exact second run이 성공하고 두 번째 실행은 zero mutation이다.
- 실패·경계 조건: Existing mismatch, unexpected entry, symlink와 injected write/rename failure에서 typed failure를 반환하고 before/after snapshot이 동일하다.
- 검사 방법: Real filesystem HOME fixtures, symlink fixtures, atomic commit fault injection, recursive metadata/hash snapshot으로 검사한다.

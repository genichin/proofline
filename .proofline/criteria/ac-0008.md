# 공용 ProofLine uv tool environment

## Criterion

Main, 모든 Line worktree와 모든 ProofLine 적용 project의 governance command는 application project의 dependency·lockfile·`.venv`를 변경하지 않고 OS user가 소유하는 하나의 공용 `uv tool` ProofLine environment와 executable을 사용한다. 선택된 source checkout의 non-editable bootstrap은 별도 tool venv executable을 만들고 checkout 밖의 project에서 ProofLine command를 실행할 수 있어야 한다.

## Verification

격리된 temporary `UV_TOOL_DIR`와 `UV_TOOL_BIN_DIR`에 source checkout을 설치하고 generated executable의 interpreter가 tool directory 아래인지 확인한다. Checkout 밖 temporary ProofLine project에서 공용 executable의 `validate`를 실행하며, 적용 project의 `pyproject.toml`, lockfile와 `.venv`가 생성·변경되지 않았음을 확인한다. 문서·workflow contract test는 governance가 공용 `proofline`을 사용하고 worktree별 ProofLine venv 또는 application dependency 설치를 요구하지 않는지 검사한다.

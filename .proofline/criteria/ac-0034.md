# Aggregate Local ProofLine Status

## Criterion

`proofline status`는 현재 실행 중인 설치 패키지, 현재 작업 디렉터리에서 직접 발견되는 ProofLine 프로젝트와 중앙 에이전트 스킬 registry를 하나의 읽기 전용 로컬 결과로 종합해야 한다. 패키지 구역은 version과 로컬에서 입증 가능한 distribution provenance, 프로젝트 구역은 `not-detected` 또는 exact project root와 local validation state, agent-skill 구역은 `agent-skill status`와 같은 counts와 worst state를 제공해야 한다. 사람용 출력과 versioned `--json`은 세 구역을 항상 구분해야 하며, 현재 디렉터리에 프로젝트가 없는 것은 오류가 아니어야 한다. 일부 구역이 invalid여도 안전하게 계산 가능한 다른 구역을 계속 출력한 뒤 전체 상태에 맞는 non-zero를 반환해야 한다. 명령은 상위·인접 repository 탐색, project 생성·수정, network·release lookup, agent profile 재해석과 repair를 수행하지 않아야 한다.

## Verification

- 성공 조건: Package-only, valid project, no-project, empty/mixed agent registry fixture에서 세 구역의 human·JSON 의미와 exit code가 일치하고 `not-detected`가 정상 결과여야 한다.
- 실패·경계 조건: Invalid project 또는 blocked agent record가 다른 안전한 구역을 숨기거나 mutation·network를 일으켜서는 안 되며, unrelated parent/adjacent `.proofline`을 현재 project로 채택해서는 안 된다.
- 검사 방법: Source와 installed-wheel subprocess를 package provenance, cwd project matrix와 agent registry fixture에서 실행하고 output schema·worst-state·exit matrix, network spy 및 package/project/registry/target before-after snapshot을 확인한다.

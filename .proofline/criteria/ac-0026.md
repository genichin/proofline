# Korean Authored-Content Guidance

## Criterion

ProofLine의 current canonical Discovery·REQ·AC template, 관련 authoring contract와 repository-owned skill은 사람이 작성하는 본문에 한국어 우선 원칙을 안내하고 H1 제목·구조적 heading, ID, status, YAML key, CLI, 코드, path, 고유 기술 용어 및 영어가 의미를 더 정확하게 전달하는 내용은 영어로 유지할 수 있음을 명시해야 한다. 이 지침은 자연어 validation gate가 아니어야 하며, validator·QC·CI는 artifact의 한국어 여부만으로 structurally valid한 artifact를 실패시키지 않아야 한다. Source와 exact wheel 및 initialized HOME의 managed resource는 동일한 지침과 bytes를 제공해야 한다.

## Verification

- 성공 조건: Current canonical template·contract·skill 전체가 한국어 본문 우선과 영어 제목·heading·technical content 예외를 일관되게 안내하고, source·wheel·fresh HOME resource의 path와 bytes가 일치해야 한다.
- 실패·경계 조건: 영어 authored content만 포함하지만 schema·구조·상태·placeholder 계약을 만족하는 Discovery·REQ·AC fixture는 언어 때문에 validation, QC 또는 CI에 실패하지 않아야 하며, removed legacy artifact는 current guidance 대상에 포함되지 않아야 한다.
- 검사 방법: Canonical resource inventory와 안내 문구 contract test, source↔wheel archive↔isolated HOME byte parity test 및 영어 본문을 가진 최소 schema v1 project의 `proofline validate` subprocess 결과로 확인한다.

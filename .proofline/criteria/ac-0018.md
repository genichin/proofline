# CLI and harness converge on selected update target

## Criterion

사용자가 official `proofline update`를 실행하면 selected verified wheel의 CLI executable과 Python package뿐 아니라 `~/.proofline/manifest.yaml`, contracts, templates, skills와 agent context도 함께 갱신되어야 한다. 성공 후 installed package version, console version, manifest version 및 모든 managed checksum은 동일 target wheel과 일치해야 하며 project `.proofline/` 및 application state는 byte-identical해야 한다.

## Verification

- 성공 조건: Absent/existing harness에서 update 후 CLI/package/manifest/resources가 target wheel과 일치한다.
- 실패·경계 조건: `--check`와 already-current 경로는 zero mutation이고 project state는 항상 보존된다.
- 검사 방법: Source tests, installed-wheel integration과 public old-to-new update transaction을 실행한다.

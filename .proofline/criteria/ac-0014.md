# Platform별 official installer는 verified wheel만 명시적 uv-tool 경계에 설치한다

## Criterion

Immutable exact tag의 official POSIX `install.sh`와 Windows native PowerShell `install.ps1`은 각 platform-native temporary directory에서 expected official wheel과 `SHA256SUMS`를 strict 검증하고, checksum 검증 후 user-level `uv tool install --no-config`를 사용하여 fresh install 또는 explicit `--force`만 수행해야 한다. 설치 후 selected executable의 version을 검증하고 application project를 변경하지 않아야 한다. Windows interface는 Git Bash·POSIX path translation·관리자 elevation 또는 machine-scoped PATH·registry mutation에 의존하지 않아야 한다.

## Verification

- POSIX shell과 PowerShell syntax, prerequisite·unknown option·download·checksum parse·expected filename·install·post-verification failure를 platform fixture로 검사한다.
- Wrong checksum은 uv invocation 전 nonzero이고 installer-owned temporary state만 정리되는지 확인한다.
- Existing install의 기본 거부와 explicit force command trace를 두 interface에서 확인한다.
- `install.sh`와 `install.ps1`의 selected version, immutable exact-tag URL, asset filename, checksum-before-install, fresh/force와 post-verification invariant가 일치하는지 검사한다.
- Isolated user-level tool directories에서 exact executable·distribution provenance와 version을 확인하고 representative application의 `.venv`, dependency·lockfile, Git state와 project `.proofline/` before/after snapshot을 비교한다.
- Windows 실행은 native temporary path만 사용하고 elevation 요청과 machine-scoped PATH·registry mutation이 없음을 확인한다. Public exact-tag remote read-back은 별도로 승인된 release가 있을 때 해당 release evidence가 담당하며 이 criterion update 자체가 release를 생성하도록 요구하지 않는다.

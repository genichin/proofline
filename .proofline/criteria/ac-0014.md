# One-line installer는 verified wheel만 명시적 uv-tool 경계에 설치한다

## Criterion

Immutable exact tag의 `install.sh`는 official wheel과 SHA256SUMS를 temporary directory에서 strict 검증하고 fresh install 또는 explicit `--force`만 수행하며 application project를 변경하지 않아야 한다.

## Verification

- Shell syntax, prerequisite·unknown option·download·checksum·install·post-verification failure를 fixture로 검사한다.
- Wrong checksum은 uv invocation 전 nonzero인지 확인한다.
- Existing install 기본 거부와 explicit force command trace를 확인한다.
- Fresh public raw installer 전후 representative application snapshot을 비교한다.

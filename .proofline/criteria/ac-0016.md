# Explicit user-level harness initialization

## Criterion

사용자가 명시적으로 `proofline init`을 실행하면 ProofLine은 packaged canonical resources로부터 user home의 `~/.proofline/`에 manifest, governance contracts, schema templates, ProofLine skills와 agent context를 설치해야 하며 current project와 application environment를 변경하지 않아야 한다.

## Verification

- 성공 조건: Isolated HOME에서 expected user-level topology와 resource classes가 존재하고 manifest path·SHA-256이 실제 bytes 및 installed package payload와 일치한다.
- 실패·경계 조건: Required packaged resource가 없으면 user home과 current project에 managed path를 남기지 않고 실패한다.
- 검사 방법: Isolated HOME fixture, installed wheel subprocess, manifest checksum 및 project before/after snapshot으로 검사한다.

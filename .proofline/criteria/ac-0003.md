# 직접 참조 파일 존재 검증

## Criterion

Validator는 `discovery`, `parent_req`, `criteria`, `micro_spec`, `line`에 기록된 각 정본 참조를 규칙으로 정해진 저장소 상대 경로로 해석하고 대상 정본 파일이 존재하지 않으면 참조를 소유한 파일을 오류로 판정해야 한다. 참조 대상의 의미와 집합 불변식은 판정하지 않는다.

## Verification

- 성공 조건: 모든 직접 참조 대상이 존재하는 최소 프로젝트 예제에서 참조 오류가 발생하지 않는다.
- 실패·경계 조건: 각 참조 종류의 대상 파일이 누락된 예제에서 참조를 소유한 파일과 누락된 대상 ID가 진단되며 입력 파일은 변경되지 않는다.
- 검사 방법: 참조 종류별 누락 예제를 CLI로 검사하고 0이 아닌 종료 코드, 소유 파일 경로와 누락 대상 ID를 확인한다.

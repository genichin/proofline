# Main-owned exact handoff 기반 implementation worktree

## Criterion

Implementation worktree는 lead/orchestrator가 main에서 exact approved specification baseline `A`의 Discovery `confirmed`, REQ `approved`, target AC approval과 Line `not_started`를 검증한 뒤 해당 Line 한 파일의 `not_started → in_progress`만 포함한 direct first-parent handoff commit `H`를 영속화하고, exact `H`에서 stable Line identity와 dedicated branch·repository-local linked worktree로 생성해야 한다. Prior draft transition은 선택적 audit evidence이며 direct approval도 허용한다. Handoff preflight는 main cleanliness, `A` identity, expected status-only `H`, branch·path·worktree-registration collision을 mutation 전에 fail-closed하게 검사해야 한다. 성공 시 허용되는 main delta는 main ref의 `A → H` 전진과 대상 Line 한 파일의 status-only 변경뿐이며, index/worktree는 clean하고 그 밖의 main artifact·ref·worktree registration·filesystem path는 preflight가 선언한 exact 생성 결과 외 불변이어야 한다. 생성 후 worktree HEAD·branch base가 exact `H`이고 main checkout이 attached `main` at `H`인지 read-back해야 한다. `H` 이후 worktree 생성이 실패하면 history를 reset/rewrite하거나 Line을 `not_started`로 되돌리지 않고 exact `H`와 `in_progress`를 유지하여 같은 identity에서 idempotent하게 재시도하며, 복구 불가능한 종료는 `cancelled` transition을 사용해야 한다. 구현 에이전트는 인계된 Line worktree만 변경하고 main checkout·main ref·Discovery·REQ·AC를 변경하지 않아야 한다.

## Verification

- 성공 조건: Recorded/direct approval baseline 모두에서 exact AC 상태와 direct status-only `A → H`를 검증하고 exact-H worktree를 생성해야 한다. Main ref와 target Line bytes에는 선언된 handoff delta만 존재하고 main index/worktree는 clean하며 다른 artifacts·refs·registrations·paths는 불변이어야 한다. Recoverable post-H failure는 같은 `H`에서 재시도해 단일 expected branch·registration·path로 수렴해야 한다.
- 실패·경계 조건: Draft/withdrawn Discovery·REQ, inactive·draft·missing target AC, non-status-only 또는 non-direct-child `H`, already-started Line, dirty main, branch/path/registration collision, wrong requested SHA와 partial mutation은 stable non-zero diagnostic으로 거부해야 한다. Pre-H failure는 ref·registration·path를 변경하지 않고 post-H failure는 persisted `H` 외 추가 mutation을 남기지 않아야 한다.
- 검사 방법: Temporary Real-Git project에서 recorded/direct approval, no/draft Micro-SPEC future flow, Line 0020 bootstrap, exact `A → H` graph, collision·failure injection과 same-H retry를 source script 및 packaged/isolated-wheel resource로 실행한다. Main symbolic HEAD·ref·target Line status-only delta, other refs, worktree porcelain, index/tree, registrations와 filesystem targets를 전후 비교한다.

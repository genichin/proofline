# Exact approval commit 기반 Line worktree

## Criterion

승인된 Line implementation을 시작하면 main checkout은 `main`과 clean governance state를 유지하고, 같은 Line의 exact REQ approval commit에서 생성된 implementation branch가 `.worktrees/line-NNNN/` linked worktree에 checkout된다. 생성 전 path·branch·registration·state 충돌은 no-mutation으로 실패하고, worktree에는 ProofLine 전용 venv를 만들지 않는다.

## Verification

Temporary Git fixture와 repository-owned workflow contract test에서 valid approved baseline은 expected path·branch·base를 생성하고 main checkout branch를 변경하지 않아야 한다. Dirty main, 잘못된 approval commit, 기존 path·branch·worktree registration은 non-zero 또는 명시적 failure로 종료하며 기존 tree를 변경하지 않아야 한다. `.worktrees/` ignore, repository-owned workflow, exact-base 검증과 ProofLine venv 미생성 규칙을 자동 검사한다.

# Hosted candidate harness clean-runner preflight

## Objective

Exact integration candidate를 remote candidate ref에 push하기 전에 candidate harness의 dependency/cache/network policy, exact wheel 입력, Ubuntu·Windows command construction과 외부 상태 의존성을 clean temporary environment에서 검증하는 non-authoritative preflight를 제공하여 harness-owned attempt-1 실패를 조기에 차단한다.

## Scope

- Empty dependency cache와 clean temporary environment에서 실행하는 preflight entrypoint와 stable outcome을 제공한다.
- Exact candidate commit, 이미 한 번 생성된 단일 candidate wheel과 wheel filename·SHA-256을 candidate commit에 결속한 strict provenance record를 입력으로 고정한다. Preflight 자체의 ProofLine wheel build/rebuild와 stale·multiple·alternate artifact 선택을 거부한다.
- Harness dependency의 online mode와 명시적 wheelhouse/cache 기반 offline mode를 분리하고 두 mode가 동일한 candidate identity와 command contract를 유지하도록 한다.
- Shared command/resource owner가 생성하는 bounded command plan에 endpoint·version source·network mode·publication prerequisite를 명시하고, candidate workflow, source와 packaged helper의 plan/resource parity를 검증한다.
- Warm-cache negative control, online/offline positive·negative provisioning, candidate/provenance/checksum mismatch, fallback/source rebuild, undeclared·mutable external-state dependency와 no-mutation regression을 제공한다.
- Preflight와 mandatory hosted Ubuntu/Windows evidence 및 DQC authority의 경계를 contract와 executable tests에서 분리한다.

## Constraints

- Preflight는 remote ref·workflow·artifact를 생성하지 않으며 Git refs·index·worktree, project와 HOME을 변경하지 않아야 한다.
- Native Windows transaction과 platform-specific runtime 판정은 mandatory hosted Windows job이 계속 소유한다.
- Preflight 결과는 hosted run/job/artifact evidence 또는 IQC·DQC PASS로 사용하지 않는다.

## Non-Goals

- 전체 Windows candidate transaction의 local emulation 또는 hosted Windows evidence 대체
- Mandatory hosted DQC policy, same-candidate retry 또는 fresh rework semantics 변경
- Production updater·installer, public Release discovery 또는 user-facing CLI 동작 변경
- Remote candidate push, workflow dispatch, main integration, tag·Release·package publication 자동화
- Usage attribution 또는 batch threat-model review 기능

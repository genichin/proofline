# Line execution lifecycle 제거

## Objective

Line을 Discovery와 REQ를 묶는 stable identity로만 유지하고 작업·검증·delivery 상태를 ProofLine canonical schema에서 제거한다.

## Scope

- Line의 필수 schema를 `id` 하나로 축소한다.
- 신규 Line template과 writer output에서 `execution_status`를 제거한다.
- 기존 `execution_status`와 `implementation_history`는 값을 해석하지 않는 deprecated optional metadata로 허용한다.
- Line lifecycle contract와 관련 skill·CI·test 기대를 identity contract로 전환한다.
- Discovery, REQ, AC status validation과 Line identity ledger를 유지한다.

## Constraints

- 기존 Line artifact bytes와 Git history를 소급 변경하거나 삭제하지 않는다.
- Deprecated Line metadata 외의 unknown field는 계속 거부한다.
- Source와 installed wheel의 Line init 결과가 동일해야 한다.

## Non-Goals

- 프로젝트별 작업 상태, 구현 진행률, 검증 또는 배포 상태를 대체 관리하는 기능
- Discovery, REQ 또는 AC lifecycle 제거
- Line ID allocation과 재사용 방지 제거

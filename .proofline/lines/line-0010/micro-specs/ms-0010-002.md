# Fail-closed idempotent user-home init transaction

## Scope

### 담당 범위

- Exact no-op, conflict·symlink detection과 all-or-nothing commit을 구현한다.
- Managed user harness allowlist와 unexpected entry 검사를 구현한다.
- Failure가 existing HOME bytes를 변경하지 않음을 검증한다.

### 제외 범위

- Harness migration·update와 conflict 자동 해결은 하지 않는다.
- Project artifact validation을 init transaction이 대신하지 않는다.

### 기준과 의존성

- `~/.proofline/` 전체가 init이 소유하는 immutable managed tree다.
- Existing non-exact target는 opaque하게 보존하고 conflict로 실패한다.

## Implementation

### 변경 대상

- `src/proofline/home_writer.py`
- `tests/test_home_init.py`
- `docs/contracts/storage-and-retention.md`

### 구현 작업

1. Target symlink, exact tree와 managed allowlist preflight를 구현한다.
2. HOME 내부 staging과 atomic no-replace directory commit을 구현한다.
3. Exact idempotent no-op를 구현한다.
4. Conflict, concurrent appearance와 injected write/rename failure no-mutation tests를 작성한다.

### Implementation result

HOME 내부 staging tree를 완전히 검증한 뒤 Linux `renameat2(RENAME_NOREPLACE)`로 absent `~/.proofline`에 단일 commit한다. Existing target는 exact match일 때만 no-op이며 그 외에는 opaque하게 보존하고 실패한다.

### Rollback과 containment

- Mutation 전에 payload와 existing target를 전부 preflight한다.
- Commit 전 failure는 staging만 제거하며 existing target는 rollback 대상으로 삼지 않는다.
- Concurrent target가 나타나면 overwrite하지 않고 staging을 제거한다.

## Verification

- 검사: Recursive path/type/mode/SHA snapshot, repeated init, mismatch·unexpected·symlink와 fault injection
- 기대 결과: Fresh/no-op만 성공하고 모든 failure fixture는 exact pre-state를 보존한다.

# Packaged user harness and explicit init command

## Scope

### 담당 범위

- Canonical contracts, templates, ProofLine skills와 agent context를 wheel resource로 package한다.
- `proofline init [--dry-run]`과 `~/.proofline/` topology·manifest를 구현한다.
- Current project no-mutation을 검증한다.

### 제외 범위

- Existing harness conflict transaction은 ms-0010-002가 담당한다.
- Project artifact bootstrap과 Hermes profile 변경은 하지 않는다.

### 기준과 의존성

- Approval baseline은 `00d428f93f37aa60495cb6b562d69e2b8ba3b86b`이다.

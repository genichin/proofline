# Packaged project harness and explicit init command

## Scope

### 담당 범위

- Canonical contracts, templates, ProofLine skills와 agent context를 wheel resource로 package한다.
- `proofline init [--dry-run]` CLI와 expected project topology·manifest를 구현한다.
- Fresh Git root가 validation과 후속 Line init precondition을 만족하도록 한다.

### 제외 범위

- Existing harness mismatch·rollback 세부 transaction은 ms-0010-002가 담당한다.
- Global Hermes skill registry와 project context file 변경은 하지 않는다.

### 기준과 의존성

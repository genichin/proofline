# 구현 이력 검증 계층 제거

## Objective

ProofLine을 Line, Discovery, REQ와 AC의 보존·구조 검증 도구로 축소하고 구현 commit provenance와 검증·통합 chronology를 제품 보증 범위에서 제거한다.

## Scope

- 구현 이력 분석기와 `proofline validate` 연결을 제거한다.
- Micro-SPEC, IQC, DQC, integration manifest와 legacy migration을 신규 canonical artifact 범위에서 제거한다.
- 구현 이력 전용 template, skill, operation, CI와 test를 제거한다.
- 기존 제거 대상 artifact와 `implementation_history` metadata는 생성하거나 해석하지 않고 보존 호환 입력으로만 허용한다.
- REQ와 AC의 현재 구조·참조·상태 검증, AC update 중 last-active binding 및 Line identity ledger를 유지한다.

## Constraints

- 기존 `.proofline/` artifact와 Git history를 삭제하거나 소급 변환하지 않는다.
- Exact legacy path 밖의 임의 파일과 directory는 계속 거부한다.
- `proofline validate`, 전체 pytest, source compilation과 wheel packaging이 통과해야 한다.

## Non-Goals

- 구현 완료, 테스트 결과, branch, merge, delivery 또는 release 품질 인증
- 제거된 artifact를 새 schema로 migration하거나 과거 결과를 재판정하는 기능
- Line identity ledger와 AC 보존에 필요한 Git 조회 제거

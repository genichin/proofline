# Atomic CLI and user harness update

## Objective

Official `proofline update`가 selected target wheel의 CLI/package와 user-level `~/.proofline/` managed harness를 동일 target version으로 갱신해야 한다.

## Scope

- Mutation 전 current installation ownership, target checksum과 current harness integrity를 검증한다.
- Target wheel 내부 resource inventory로 새 manifest와 managed tree를 구성한다.
- Absent harness는 생성하고 existing exact old harness는 atomic replacement한다.
- CLI 설치 또는 harness commit 실패는 old coherent state를 보존·복원한다.
- 성공 후 installed package, console, manifest version과 managed checksum을 재검증한다.
- `--check`는 package/harness mutation 없이 계획만 반환한다.

## Constraints

- Checksum verification, provenance, idempotency, no-overwrite, no-symlink, all-or-nothing, fail-closed 원칙을 유지한다.
- Project `.proofline/`, `.venv`, dependencies, lockfile와 Git state를 변경하지 않는다.
- Release version, tag, wheel digest와 publication은 IQC/DQC evidence로 기록한다.

## Non-Goals

- 사용자 변경 resource merge 또는 unexpected file migration
- Project canonical artifact/schema migration
- Git operation과 non-official update channel

# Agent Skill Installation Management

## Objective

ProofLine의 기준 스킬을 설치된 패키지 또는 검증된 대상 휠에서 Hermes·Codex의 실제 스킬 탐색 위치로 안전하게 복사하고, 운영체제 기본 사용자 상태 위치의 설치별 등록 정보로 setup·adopt·remove·repair·unregister·status·doctor와 패키지 업데이트 동기화를 관리한다. 동시에 `proofline init`과 관리 대상 `~/.proofline/` 생명주기를 제거하고 패키지·프로젝트·에이전트 설치 상태를 명시적인 읽기 전용 인터페이스로 제공한다.

## Scope

- Hermes 프로필과 Codex 사용자 범위의 실제 스킬 대상을 읽기 전용으로 해석하고, 어댑터별 고정된 복사 전용 배치 구조를 적용한다.
- 운영체제 기본 사용자 상태 디렉터리에 설치별 매니페스트 파일 집합을 두고, 닫힌 스키마·경로 안전성·파일 해시·소유권으로 등록 설치를 판정한다.
- `proofline agent-skill setup`, `remove`, `repair`, `unregister`, `status`, `doctor`와 exact-existing 대상의 명시적 `--adopt-existing` 경로를 제공한다.
- `proofline status`가 현재 패키지, 현재 작업 디렉터리의 ProofLine 프로젝트, 중앙 에이전트 설치 요약을 로컬에서 종합하도록 한다.
- 기본 `proofline update`가 등록된 모든 에이전트 설치를 선택한 휠과 함께 갱신하고, `--no-sync-agent-skills`와 `--check`의 무변경·진단 경계를 제공하도록 한다.
- 대상별 준비·재확인, 잠금, durable journal, 검증된 백업과 소유권 기반 복구로 정상 오류와 강제 종료·전원 손실 뒤의 중단 트랜잭션을 감지·복구한다.
- 공개 `v0.7.0` wheel에서 HOME 폐기 첫 릴리스로의 공식 전환을 exact-tag installer 강제 재설치로 검증하고 이후 업데이터에서 HOME 규약을 제거한다.
- 계약·템플릿·작업 절차·저장소 소유 스킬·패키지 자원에서 `proofline init`, 관리 대상 `~/.proofline/`, source·wheel·HOME 일치 주장을 현재 제품 생명주기에서 제거한다.

## Constraints

- 설치와 갱신은 복사 전용이며 심볼릭 링크·하드 링크·Windows 정션, 에이전트 설정 수정과 광범위한 덮어쓰기 `--force`를 사용하지 않는다.
- 제품 동작은 기존 `~/.proofline/`을 생성·읽기·변경·백업·삭제하거나 에이전트 원본으로 재사용하지 않는다.
- 에이전트 대상과 중앙 등록 정보의 경로·형식·해시·소유권을 변경 전에 보수적으로 검증하며, 모호하거나 안전하지 않은 상태에서는 추측하지 않고 중단한다.
- 여러 파일시스템 전체의 운영체제 수준 원자성은 주장하지 않으며, journal·백업·복구·최종 재확인으로 성공 상태의 휠 식별자 일치를 판정한다.
- Windows 패키지 교체는 현재 프로세스 종료를 확인한 detached helper를 사용하고 결과 재확인 전 성공을 반환하지 않는다.
- 테스트는 격리된 도구·HOME·상태·에이전트 대상만 사용하며 실제 사용자 경로, 응용 프로젝트, Git 상태와 원격 자원을 변경하지 않는다.
- 사용자 승인 전 이 REQ와 create/update AC는 draft이며 구현 기준선이 아니다. `retire` 대상 `ac-0016`은 승인 전까지 active body를 그대로 보존한다.

## Non-Goals

- 기존 `~/.proofline/`의 자동 삭제·이전·백업·등록 또는 새 설치 원본으로의 재사용
- Hermes·Codex 이외 어댑터, 시스템 전체·관리자 범위 또는 저장소 지역 설치
- 에이전트 설정 재작성, 링크 기반 설치, 사용자 수정 파일 병합과 암묵적 기존 대상 채택
- 에이전트 실행 중 즉시 다시 읽기, 상주 감시, 백그라운드 자동 동기화와 세션 사용 이력 판정
- 응용 프로젝트 `.proofline/`, 의존성·잠금 파일, Git branch·worktree와 원격 저장소 변경
- 실제 사용자 에이전트 대상의 설치·삭제 실행, 릴리스 버전·태그 생성과 파일 게시
- 기존 릴리스·Line·REQ·AC·태그·게시 이력의 소급 수정

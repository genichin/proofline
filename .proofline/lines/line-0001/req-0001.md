# 최소 validator MVP

## Objective

ProofLine 스키마 버전 1의 프로젝트 설정과 정본 산출 문서에서 핵심 구조 오류를 일관되게 탐지하는 `proofline validate` 명령을 제공한다.

## Scope

- 루트 `proofline.yaml`의 필수 항목과 고정값을 검사한다.
- `.proofline/` 아래 정본 산출 문서의 YAML 머리말, 상태값, 파일명·ID, H1·H2 및 자리표시자를 검사한다.
- 정본 참조가 규칙으로 정해진 대상 파일 경로에 존재하는지 검사한다.
- 정상 예제에는 종료 코드 0을, 오류 예제에는 0이 아닌 종료 코드와 파일 경로·오류 원인을 반환한다.
- 하나의 Micro-SPEC으로 구현하고 대표 정상·오류 예제로 검증한다.

## Constraints

- 검사는 로컬 저장소 안에서 결정적으로 실행하며 네트워크나 원격 서비스에 의존하지 않는다.
- 첫 구현은 이 REQ가 생성하는 AC만 충족하며 추가 계약 검사는 후속 Line으로 분리한다.
- 문서 계약과 구현이 충돌하면 `docs/artifact-layout.md`와 `docs/contracts/`를 우선한다.

## Non-Goals

- 산출 문서 생성과 자동 ID 할당
- 상태 전이와 승인 권한 자동화
- Git 커밋 계보, fast-forward 및 IQC·DQC 커밋 결합 검증
- 참조 의미와 AC·Micro-SPEC 집합 불변식 검증
- 파생 요구사항 문서 생성, 자동 수정, 플러그인 및 Hermes Agent 배포

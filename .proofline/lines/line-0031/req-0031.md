# Korean Authored-Content Guidance

## Objective

Canonical artifact의 영어 제목·heading을 유지하면서 사람이 작성하는 본문에는 한국어 우선 원칙과 영어 예외 경계를 일관되게 안내하되, artifact 언어를 validator·QC·CI의 PASS/FAIL 조건으로 만들지 않는다.

## Scope

- Discovery·REQ·AC template의 authored-content placeholder에 한국어 우선 작성 원칙을 명시한다.
- Repository-owned Line·Requirement·Specification authoring skill과 관련 contract를 같은 언어 경계에 맞춘다.
- H1 제목, 구조적 heading, ID, status, YAML key, CLI, 코드, path, 고유 기술 용어 및 영어가 의미를 더 정확하게 전달하는 내용은 영어로 유지할 수 있음을 명시한다.
- Validator는 artifact의 자연어를 판정하지 않으며 영어 authored content를 포함한 구조적으로 유효한 artifact를 언어만으로 거부하지 않는다.
- QC와 CI는 source template·contract·skill 및 wheel·HOME resource의 지침과 exact parity만 검증한다.

## Constraints

- 기존 canonical artifact의 bytes와 Git history를 번역하거나 migration하지 않는다.
- 자연어 분류, Hangul 문자·비율 검사 또는 영어 예외 marker를 도입하지 않는다.
- 제거된 legacy artifact의 template·contract·skill을 복원하지 않는다.
- 사용자만 REQ와 AC approval authority를 가지며 이 draft는 구현 기준선이 아니다.

## Non-Goals

- 한국어 작성 여부를 이유로 `proofline validate`, QC 또는 CI를 실패시키는 기능
- Artifact H1 제목·구조적 heading, identifier와 technical token의 한국어 번역
- 기존 영문 artifact의 자동 번역·수정 또는 compatibility migration
- Line·Discovery·REQ·AC lifecycle과 approval 절차 변경

# Line bootstrap AC 통합

## Scope

### 담당 범위

- `ac-0005`의 preflight·dry-run·no-overwrite·atomic failure 조건을 `ac-0004`에 통합한다.
- `ac-0005`를 `ac-0004`로 대체된 중복 AC로 retire한다.

### 제외 범위

- Line writer와 validator의 제품 코드 및 test 변경
- 기존 Line bootstrap 동작의 의미 변경

### 기준과 의존성

- `ac-0004`와 `ac-0005`의 현재 active revision 및 기존 Line 0002 evidence
- AC lifecycle과 canonical terminal artifact 보존 계약

## Implementation

### 변경 대상

- `.proofline/criteria/ac-0004.md`
- `.proofline/criteria/ac-0005.md`

### 구현 작업

1. 두 AC의 Criterion과 Verification을 condition matrix로 대조한다.
2. 누락 없이 `ac-0004`의 정상·실패·경계 조건으로 통합한다.
3. `ac-0005`에 survivor와 retirement 사유를 기록하고 `retired`로 전환한다.
4. 기존 Line 참조와 current canonical validation을 확인한다.

### Rollback과 containment

- 승인 baseline 이전에는 두 AC를 함께 되돌린다. 통합 조건 누락이나 dangling reference가 있으면 lifecycle transition을 수행하지 않는다.

## Verification

- 검사: 두 AC semantic diff, 직접 참조 검색, `proofline validate`, `git diff --check`
- 기대 결과: `ac-0004`가 기존 두 AC의 조건을 모두 소유하고 `ac-0005`는 고정 경로에서 retired 상태로 보존된다.
- Evidence: `iqc-0012-001.md`

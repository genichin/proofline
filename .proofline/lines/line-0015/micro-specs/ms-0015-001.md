# Anchored atomic no-replace Line commit

## Scope

### 담당 범위

- `proofline line init`의 parent identity 보호와 atomic no-replace target commit을 구현한다.
- One-shot `.proofline`·`lines` parent replacement와 commit-boundary target appearance에서 repository 밖 write와 existing target 교체를 방지한다.

### 제외 범위

- Template/render failure transaction과 installed-wheel E2E는 별도 Micro-SPEC이 담당한다.
- Private staging takeover, syscall interposition과 반복 adversarial path 교체는 담당하지 않는다.

### 기준과 의존성

- Confirmed `dcy-0015`, approval 예정 `req-0015`, active `ac-0004`와 current `src/proofline/line_writer.py`를 기준으로 한다.
- Required filesystem capability는 mutation 전에 확인하고 unsupported 환경에서는 typed failure를 반환해야 한다.

## Implementation

### 변경 대상

- `src/proofline/line_writer.py`의 safe-path preflight, staging ownership과 commit primitive
- Parent replacement, empty target와 concurrent target regression tests

### 구현 작업

1. `.proofline`과 `lines`의 non-symlink directory identity를 descendant lookup·commit 전에 고정하고 commit 시점까지 검증한다.
2. Existing file·symlink·empty/non-empty directory를 모두 교체하지 않는 atomic no-replace target commit을 구현한다.
3. Parent가 preflight 이후 한 번 교체되면 anchored identity 밖에 쓰지 않고 stable typed diagnostic으로 실패한다.
4. 경쟁 target은 보존하고 이번 invocation이 소유한 staging·partial path만 rollback한다.
5. 실제 Linux filesystem race와 deterministic synchronization hook으로 commit 경계 behavior를 검증한다.

### Rollback과 containment

- ProofLine-owned staging identity와 expected artifact bytes를 확인한 path만 정리하며 pre-existing·concurrent target은 삭제하거나 교체하지 않는다.
- Identity 또는 atomicity를 증명할 수 없으면 project mutation 전에 실패한다.

## Verification

- 검사: 실제 parent swap, existing empty target, file·symlink·directory target appearance와 atomic no-replace focused tests를 실행한다.
- 기대 결과: 모든 경쟁 target과 repository 밖 tree가 보존되고 stable non-zero diagnostic과 owned staging 부재가 확인된다.
- Evidence: `.proofline/lines/line-0015/micro-specs/iqc-0015-001.md`에 exact specification·implementation commit, filesystem과 test 결과를 기록한다.

# Actual-filesystem race와 installed-wheel Line init E2E

## Scope

### 담당 범위

- Source와 exact installed candidate wheel에서 Line init success, dry-run, no-replace race, failure cleanup과 generated project validation을 독립적으로 검증한다.
- Mocked exception만이 아니라 실제 Linux filesystem의 parent replacement와 existing empty target behavior를 regression으로 고정한다.

### 제외 범위

- Writer commit·rollback implementation은 `ms-0015-001`과 `ms-0015-002`가 담당한다.
- Package release publication, updater와 version-independent AC에 wheel digest를 포함하는 작업은 담당하지 않는다.

### 기준과 의존성

- `ms-0015-001`의 anchored no-replace commit과 `ms-0015-002`의 failure transaction이 구현된 exact candidate에 의존한다.
- Candidate wheel은 checkout 밖 isolated HOME·tool directory·Git project에서 실행하며 live installed CLI와 `~/.proofline/`을 변경하지 않는다.

## Implementation

### 변경 대상

- `tests/test_line_init.py` actual-filesystem race fixtures
- Wheel build/resource inclusion과 checkout-outside CLI E2E tests 및 IQC provenance evidence

### 구현 작업

1. Deterministic process synchronization으로 preflight 이후 parent를 external symlink·다른 object로 한 번 교체하고 outside tree 불변을 확인한다.
2. Existing empty directory와 file·symlink·non-empty directory가 commit 경계에 나타나는 실제 target race를 실행하고 no-replace를 확인한다.
3. Exact candidate wheel을 isolated environment에 설치하고 executable path, reported version, candidate commit과 wheel SHA-256을 고정한다.
4. Fresh initialized project에서 installed Line init dry-run·actual·collision·failure cleanup과 `proofline validate`를 실행한다.
5. Source와 installed wheel의 output paths, canonical bytes, diagnostics와 no-mutation behavior를 비교한다.

### Rollback과 containment

- 모든 race·wheel E2E fixture는 temporary repository, external sentinel directory, HOME과 tool directory에서만 실행하고 repository source·live home·installed tool을 변경하지 않는다.

## Verification

- 검사: Actual Linux filesystem race suite, exact-wheel checkout-outside E2E, full regression과 source canonical validation을 실행한다.
- 기대 결과: Source와 installed wheel 모두 두 canonical artifacts만 생성하고 보장 대상 race·failure에서 external/competing tree를 보존하며 owned residue를 남기지 않는다.
- Evidence: `.proofline/lines/line-0015/micro-specs/iqc-0015-003.md`에 candidate·wheel provenance, race output과 E2E 결과를 기록한다.

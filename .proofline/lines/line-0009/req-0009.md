# Checksum-verified one-line installer

## Objective

사용자는 one-line command로 ProofLine을 설치하되 installer 내부에서 official wheel checksum을 strict 검증하고 application project를 변경하지 않아야 한다.

## Scope

1. Root `install.sh`는 POSIX shell로 실행되고 selected stable version의 immutable official release URL을 사용해야 한다.
2. `curl`, `sha256sum`, `uv` 누락 시 package mutation 전에 nonzero로 종료해야 한다.
3. Unique temporary directory를 생성하고 모든 종료 경로에서 정리해야 한다.
4. Wheel과 SHA256SUMS를 HTTPS로 download하고 exact expected filename과 strict checksum이 유효할 때만 install해야 한다.
5. 기본 실행은 `uv tool install --no-config <verified-wheel>`을 사용하고 existing installation을 자동 overwrite하지 않아야 한다.
6. Installer `--force`가 명시된 경우에만 `uv tool install --force --no-config <verified-wheel>`을 사용해야 한다.
7. Unknown option은 usage와 nonzero를 반환해야 한다.
8. 설치 후 `uv tool dir --bin`의 `proofline --version`이 target version과 일치해야 성공해야 한다.
9. Installer는 application cwd의 `.venv`, `pyproject.toml`, lockfile, Git state와 `.proofline/`을 변경하지 않아야 한다.
10. README 기본 설치는 selected stable version의 immutable exact tag raw installer one-line command이고 manual strict workflow는 대안으로 제공해야 한다.
11. Public raw installer fresh install에서 checksum, archive provenance, application no-mutation을 검증할 수 있어야 한다.

## Constraints

- Installer script는 credential 값을 읽거나 보존·출력하지 않는다.
- Mutable main·branch raw URL을 사용자 설치 명령으로 제공하지 않는다.
- Existing published tags·Releases·assets를 수정·삭제하지 않는다.
- Git operation과 project lifecycle은 installer가 수행하지 않는다.

## Non-Goals

- PyPI publication
- Windows PowerShell installer
- Automatic background update 또는 rollback
- Installer Release upload asset 추가
- Application schema·artifact migration
- 특정 version·tag·candidate·wheel identity 또는 publication 결과를 active AC로 관리

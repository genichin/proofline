# Checksum-verified POSIX installer

## Scope

### 담당 범위

- Root `install.sh` prerequisite, option, download, checksum, uv install, post-verification과 cleanup
- README one-line default와 manual strict verification
- Installer fixture·shell syntax·no-mutation tests

### 제외 범위

- Remote tag·Release publication
- PyPI·PowerShell installer

### 기준과 의존성

- Target version은 `0.2.2`다.
- User-facing URL은 immutable raw exact tag를 사용한다.
- Existing installation은 기본 overwrite하지 않고 explicit `--force`만 허용한다.

## Implementation

### 변경 대상

- `install.sh`, `README.md`, installer tests

### 구현 작업

1. Installer tests와 fake command fixture를 RED로 작성한다.
2. POSIX `install.sh`를 최소 구현해 GREEN으로 만든다.
3. README 기본 설치를 one-line으로 바꾸고 manual procedure를 보존한다.
4. Full regression과 representative application snapshot을 검증한다.

### Rollback과 containment

- Checksum·prerequisite·download 실패는 uv install 전에 중단한다.
- Temporary directory는 trap으로 정리한다.
- Existing installation은 `--force` 없이는 uv 자체 fail-closed behavior를 유지한다.

- 검사: `sh -n`, fake fresh/force/checksum/prerequisite/postverify paths, application snapshot, README contract
- 기대 결과: verified wheel만 install되고 one-line UX와 no-mutation이 충족됨
- Evidence: `iqc-0009-001.md`
